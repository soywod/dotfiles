# dotfiles

NixOS configurations, one per host in `hosts/`.

## Install

From the NixOS installer, with the exported GPG secret key on a USB stick:

```sh
sudo nix --extra-experimental-features 'nix-command flakes' \
  run github:soywod/dotfiles#install -- [--disk /dev/nvme0n1] [--mount /mnt] soywod /path/to/secret-key.asc
```

It partitions the disk with the host's `disko.nix` (wiping it, after confirmation), installs the system, then runs `bootstrap`. Reboot when it is done.

For new hardware, first create `hosts/<name>/` with a `hardware-configuration.nix` generated by:

```sh
nixos-generate-config --no-filesystems --show-hardware-config
```

## Bootstrap

`bootstrap` imports the GPG key, uses its authentication subkey as SSH key, clones every repository declared in `programs.mr` and installs the key into `~/.gnupg`. On an already installed system:

```sh
nix run github:soywod/dotfiles#bootstrap -- /path/to/secret-key.asc
```

The key needs an authentication subkey:

```sh
gpg --quick-add-key <fingerprint> ed25519 auth
gpg --export-secret-keys --armor <fingerprint> > secret-key.asc
gpg --export-ssh-key <fingerprint>
```
